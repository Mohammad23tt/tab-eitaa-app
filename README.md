# تب (Tab) — پلتفرم تبلیغات حرفه‌ای برای پیام‌رسان ایتا

یک برنامک حرفه‌ای برای ایجاد و مدیریت کمپین‌های تبلیغاتی داخل ایتا.

## لینک مخزن
https://github.com/Mohammad23tt/tab-eitaa-app

## ویژگی‌ها
- داشبورد آماری
- ایجاد تبلیغ با بنر و هدف‌گیری کانال
- پیش‌نمایش کانال
- پنل کاربری حرفه‌ای
- پشتیبانی کامل از تم و RTL ایتا

## نحوه استفاده
۱. مخزن را کلون کنید یا از GitHub Pages استفاده کنید.
۲. در ایتایار ثبت کنید.
۳. آدرس HTTPS را به عنوان آدرس مقصد وارد کنید.
